INFORMAÇÃO AO VISITANTE

Privacidade e inscrições

Este site é uma página estática de divulgação do projeto União Desportiva dos Templários – Vale do Calvo.

Formulário de inscrição

O formulário funciona no teu dispositivo. Os dados introduzidos não são guardados numa base de dados do site nem enviados automaticamente. Ao escolheres «Abrir email para enviar», é criada uma mensagem no teu programa de correio, endereçada a u.d.templarios@gmail.com. Só é enviada quando confirmares no teu programa de email.

Dados tratados

O pedido pode incluir nome, email, telefone, tipo de inscrição, modalidades, faixa etária e observações. São utilizados para análise do pedido e contacto sobre a inscrição. Evita enviar documentos de identificação, NIF, moradas ou dados de saúde por este formulário.

Menores

Pedidos relativos a menores dependem de autorização do representante legal. O formulário não substitui essa autorização.

Retenção e direitos

Após o envio do email, o tratamento e conservação dos dados dependem dos procedimentos internos da associação e do serviço de correio utilizado. Podes solicitar informações, retificação ou eliminação dos teus dados através de u.d.templarios@gmail.com, sem prejuízo das obrigações legais aplicáveis.

Alojamento

O alojamento do site, caso seja publicado no GitHub Pages, pode implicar registos técnicos tratados pelo fornecedor do serviço. Esta página não utiliza cookies analíticos nem ferramentas próprias de rastreio.
